listing description
Home Asset + Warranty turns a phone photo of an invoice into warranty tracking: OCR reads it, you confirm, and a single digest reminder lands at 30/7/0 days via Telegram, Discord, email, or push. One Docker container, your own hardware, nothing leaves the house.

Features

  • 01
    OCR invoice capture

    Photo or PDF of an invoice suggests brand, model, serial, store, invoice number, date, total and warranty length — you just confirm it.

  • 02
    Warranty math, handled

    Expiry = start + N months − 1 day. Extended warranty / AMC chains onto the manufacturer warranty automatically, or type an exact date.

  • 03
    One digest, not a flood

    30/7/0-day reminders collapse into a single message per channel — closest tier only, never sent twice, catches up if the Pi was off.

  • 04
    Four notification channels

    Telegram, Discord, email (SMTP) and ntfy push, each with its own on/off switch and a Test button.

  • 05
    Spend dashboard

    Spending by month, category and store, charted with Recharts.

  • 06
    Family accounts, no public sign-up

    Admins add members from Settings or the CLI. Nobody else can create an account.

  • 07
    Hardened by default

    Argon2id password hashes, server-side sessions, CSRF checks, login lockouts, strict CSP, uploads checked by content not extension, photos re-encoded to strip EXIF/GPS.

  • 08
    Runs on a Raspberry Pi 5

    One non-root container, read-only root filesystem, 512 MB cap, ~120–180 MB idle. Alongside your existing Postgres + Caddy, or fully standalone with its own database.

  • 09
    Open source

    MIT-style self-host — clone it, point it at your own Docker + Postgres, done.
